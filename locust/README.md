# Precious Pizza - Load Testing

This directory contains load testing scripts for the Precious Pizza application using [Locust](https://locust.io/).

## Overview

Load testing implementation with various test shapes:

- Load shape testing
- Soak testing
- Spike testing
- Stress testing

## Installation

```bash
poetry install
```

## Usage

Run the load tests:

```bash
poetry run locust
```

## Configuration

Configure test parameters in the `.env` file.
